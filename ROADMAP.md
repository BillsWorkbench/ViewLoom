# Roadmap

## Available in 0.5.3

- Develop, Weave, and Export workflow.
- Non-destructive RAW development and projects.
- Manual alignment, blending, Strength, edge fade, and layer ordering.
- Selective batch syncing from the main photograph.
- Full-resolution 16-bit TIFF export.

## Next: real-sequence testing

- Test sets of 10–20 or more views of the same subject.
- Evaluate alignment speed, blend quality, edge fade, and large-project performance.
- Test both supported camera samples across additional compression settings.
- Collect Windows installation and interface results.

## Desktop distribution

- Build standalone macOS and Windows applications.
- Validate package contents, licenses, launch behavior, and clean-machine installation.
- Decide signing/notarization and installer distribution details.

## Possible later additions

- Highlights/shadows, whites/blacks, vibrance, and histogram/clipping displays.
- Optional global finishing controls.
- Automatic subject alignment and subject protection.
- Development presets and broader camera/profile testing.

These are planning topics, not promised features or release dates. The immediate
priority is using the current tools with real photographic sequences.
